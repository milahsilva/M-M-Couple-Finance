# 💕 Couple Finance

### Building our future, together.

Couple Finance is a website created to help couples organize and manage their finances together.

The project combines web development, finance and a simple user-friendly design to make it easier to understand income, expenses, savings and financial goals.

---

## 🌐 About the Project

Couple Finance is being developed as a personal project by Mila & Mathias.

The idea is to create a simple financial dashboard where couples can manage their money together and have a clear overview of their monthly finances.

---

## ✨ Features

The website is being developed with features such as:

- 💰 Income tracking
- 💸 Expense tracking
- 📊 Monthly financial overview
- 💵 Savings tracking
- 👩‍❤️‍👨 Separate finances for each partner
- 📅 Monthly organization
- 🎯 Financial goals

---
